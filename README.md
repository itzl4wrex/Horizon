# Horizon
![Horizon Preview](Images/Image%2002.png)


A clean and customizable New Tab experience for your browser.

## 📥 Installation

Follow the steps below to install Horizon manually.

### 1. Create the Horizon folder

1. Open **File Explorer**.
2. Go to your **User folder**:

```text
C:\Users\YourUsername
```

3. Create a new folder called:

```text
Horizon
```

---

### 2. Extract the ZIP file

1. Download the latest **Horizon ZIP file**.
2. Move the ZIP file into your newly created `Horizon` folder.
3. Right-click the ZIP file and select **Extract All...**
4. Extract the files into the `Horizon` folder.
5. Once extraction is complete, **delete the ZIP file**.

Your folder should look similar to this:

```text
Horizon/
├── manifest.json
├── index.html
├── css/
├── js/
└── ...
```

> **Important:** Make sure `manifest.json` is directly inside the `Horizon` folder.

---

### 3. Open your browser

Open your browser and go to the Extensions page.

For Google Chrome, enter:

```text
chrome://extensions/
```

For Microsoft Edge:

```text
edge://extensions/
```

---

### 4. Enable Developer Mode

On the Extensions page:

1. Find **Developer mode**.
2. Turn it **ON**.

You should now see additional options, including **Load unpacked**.

---

### 5. Load Horizon

1. Click **Load unpacked**.
2. Navigate to the `Horizon` folder you created earlier.
3. Select the folder containing `manifest.json`.
4. Click **Select Folder**.

Horizon should now appear in your list of installed extensions.

---

### 6. Enjoy Horizon ✨

Open a new tab and Horizon should load automatically.

You're all set! 🎉

## ❗ Troubleshooting

If Horizon doesn't load correctly:

* Make sure you selected the **Horizon folder**, not the ZIP file.
* Make sure `manifest.json` is directly inside the selected folder.
* Make sure the ZIP file was extracted correctly.
* Try removing Horizon from your extensions and loading it again.
* Check the **Errors** button on the Horizon extension card for more information.
